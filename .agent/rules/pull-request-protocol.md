# Pull Request Protocol

## Core Directive
For each completed step or task, the AI must ask the user if a PULL REQUEST can be made for the project.

## Requirements for Action
1. **Task Completion**: Verify that the current step or task is fully complete.
2. **Prompt for PR**: Ask the user explicitly if they would like to make a Pull Request for these changes.
3. **Draft PR Details**: If the user confirms, generate a clear, descriptive name and a detailed description for the Pull Request based on the completed work.

## Goal
To maintain a clear, manageable history of completed tasks and to facilitate organized integration of new features or fixes into the main codebase.
